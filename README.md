# simply-cache
Simple dotnet library for attribute based caching.

This is the author's first open source project, so any feedback is appreciated.

The author want to implement a simple caching library for dotnet that allows you to easily cache the results of methods using attributes. The library will support both in-memory caching and distributed caching (e.g. Redis).

The main goal is for the author to learn about caching and how to implement it in a way that is easy to use and understand. The library will be designed to be simple and straightforward, with a focus on ease of use and performance.

## Features

Attribute based method caching: 
- Add a simple attribute to any method to enable caching of its results.
- Attribute parameters to control cache duration, cache key generation, and other caching behaviors.
